# FlatModern - PDF Studio 📄

FlatModern 是一個專注於 PDF 處理的高效 Web 工具，解決字體未嵌入導致的跑版與文件過大的問題。

## ✨ 核心特色

- **PDF 扁平化 (Flattening)**：使用 PyMuPDF (fitz) 真實點陣化引擎，將所有文字與向量轉為高解析度圖片重組，確保 100% 視覺還原且不可編輯。
- **雲端壓縮 (Cloud Compression)**：整合 Ghostscript 後端，平衡文件大小與圖像品質。
- **美感介面**：基於 Stone 系列色調的現代 UI。
- **PWA 支援**：支援離線載入介面，提升存取效率。

## 🛠️ 技術架構

- **Frontend**: React + Vite + Tailwind CSS
- **Backend (API)**: Python (FastAPI/Flask) 部署於 Google Cloud Run。
- **Infrastructure**: Firebase Hosting (部署於 `/pdf-tool/` 路徑)

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd pdf-tool
   ```
2. **本地開發**：
   ```bash
   npm install
   npm run dev
   ```
3. **後端連線**：
   後端 API 位址配置於 `.env.production`。

## 📌 注意事項

- 本專案在 `vite.config.js` 中設定了 `base: '/pdf-tool/'`。
- 修改 `full_deploy.sh` 時，務必確保產物複製至 `dist_release/pdf-tool/`。
