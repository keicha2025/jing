# V-Player Web App - 高效影音播放器 🎬

V-Player 是一個專業級的 Web 影音預覽與播放工具，支援高度自定義介面與極簡設計語言。

## ✨ 核心特色

- **純淨全螢幕體驗**：移除多餘導航，專注於內容呈現。
- **靈活播放策略**：支援主流瀏覽器可播放之所有格式。
- **高刷新率優化**：針對桌面與移動端高刷螢幕提供流暢的 UI 反映。
- **自定義主題樣式**：內建 Stone 與黑暗模式主題庫。
- **PWA 支援**：支援安裝至系統桌面，實現極速啟動。

## 🛠️ 技術架構

- **Frontend**: Vite + React
- **Icons**: Lucide React
- **Styling**: Tailwind CSS
- **Deployment**: Firebase Hosting (部署於 `/v-player-preview/` 路徑)

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd v-player-preview
   ```
2. **安裝依賴**：
   ```bash
   npm install
   ```
3. **本地執行**：
   ```bash
   npm run dev
   ```
4. **構建發布**：
   ```bash
   npm run build
   ```
   *注意：構建產物由 `./full_deploy.sh` 整合。*

## 📌 注意事項

- 本專案在 `vite.config.js` 中設定了 `base: '/v-player-preview/'`。
- 對 PWA 圖示的更改需同步更新 `public/` 資料夾。
