## 🌟 核心理念 (Core Philosophy)

- **美感優先 (Aesthetics First)**：採用玻璃擬態 (Glassmorphism)、深夜模式與現代字體。
- **邊緣運算 (Edge Performance)**：優先在瀏覽器本地處理數據（如 PDF 點陣化、音訊分析）。
- **跨平台 (PWA)**：所有工具均支援漸進式網頁應用 (PWA) 技術，可安裝於手機與電腦桌面。
- **數據自主 (Privacy & Sync)**：結合 Firebase 與 Google Sheets (GAS) 實現安全的雲端同步。
