# Minimalist Note - 秒開筆記 ✍️

專為「隨手記錄」而生的極簡筆記本。透過本地快取優先策略，實現接近原生的直覺體驗。

## ✨ 核心特色

- **秒開快取模式**：優先從 LocalStorage 載入資料，點擊即開，不需等待雲端回應。
- **背景自動同步**：後台靜默同步 Firebase 與 Google Sheets (GAS)，確保數據多端一致。
- **Google 登入驗證**：支援 Firebase Auth 與白名單過濾機制。
- **極簡 Stone UI**：移除多餘色彩，使用細緻的灰階與石質色調，提升專注力。
- **PWA 全支援**：支援離線查閱、離線新增，上線後即時同步更新。
- **差異對比引擎**：內建 `diff-match-patch` 處理多端同步衝突。

## 🛠️ 技術架構

- **Frontend**: HTML5, Vanilla JS, Tailwind CSS (Pruned Static Batch)
- **Backend Sync**: Google Apps Script (GAS) + Google Sheets
- **Authentication**: Firebase Authentication
- **Service Worker**: Cache-First Strategy (`note-app-v9`+)

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd note
   ```
2. **本地執行**：
   直接使用 Live Server 開啟 `index.html`。
3. **雲端連動**：
   需配置 `config.js` 中的 Firebase 與 GAS Endpoint。

## 📌 注意事項

- 本筆記本採用白名單存取，非白名單用戶僅能查閱公開內容（視權限而定）。
- 同步機制為「最終一致性」模型。
