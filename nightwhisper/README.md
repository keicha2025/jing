# NightWhisper 夜語 - 睡眠錄音與分析 🌙

NightWhisper 夜語是一個隱私優先、極簡且具備智能分析功能的睡眠追蹤工具。

## ✨ 核心特色

- **智慧錄製系統**：支援長達數小時的持續錄製，並自動分段存儲於 IndexedDB。
- **本地離線分析**：透過 FFT 與頻譜分析技術，自動辨識打呼 (Snore) 與夢話 (Talk)。
- **5 級靈敏度設定**：自由調整辨識靈敏度，過濾背景噪音。
- **高畫質轉碼**：全前端 WebCodecs 轉碼技術，下載錄音檔時自動轉為 M4A/AAC 格式。
- **上傳分析**：支援現有錄音檔上傳，提供歷史回顧與事件時間軸對齊。
- **深色沉浸式 UI**：專為夜間設計的視窗與圖表，減少光線干擾。

## 🛠️ 技術架構

- **Vanilla JS**: 無框架渲染，追求極致性能與穩定。
- **PWA**: 全脫機支援，無網路環境亦能正常錄製與分析。
- **Storage**: IndexedDB (分段音軌), LocalStorage (設定).
- **Libraries**: `mp4-muxer` (轉碼), `chart.js` (分析視覺化).
