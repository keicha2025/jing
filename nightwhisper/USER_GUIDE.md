# NightWhisper 使用指南 (User Guide)

歡迎使用 NightWhisper。本應用程式旨在幫助您在不消耗隱私的情況下（本地分析），透明地了解您的睡眠呼吸與夢話狀態。

## 智慧錄製
點擊首頁的 **「監測」** 分頁，然後點擊紅色按鈕即可開始錄音。
*   錄製過程中，系統會自動在後端將音訊切片存入本地資料庫 (IndexedDB)。
*   即使關閉分頁或系統當機，已錄製的部分也會在下次開啟時自動恢復。

## 歷史報告與互動
進入 **「歷史」** 分頁，點擊任一筆錄音紀錄。
*   您可以看到由 AI 生成的「智慧辨識時間線」。
*   **點擊標籤跳轉**：點擊時間線中的標註（如：打呼 +10s），波形圖會自動跳轉到該精確時段並開始播放，方便您立即回聽。

## 進階技巧：處理超長檔案 (9 小時+)

如果您錄製了長達 9 小時的檔案（如 400MB 的 M4A），雖然系統已優化至 8kHz 辨識，但處理時間仍長。我們提供了一個 Python 輔助工具來預過濾靜音，將 9 小時的檔案精簡至數十分鐘的精華。

### 使用 Python 過濾靜音
1. **安裝依賴**：
   ```bash
   pip install pydub
   # 並確保系統已安裝 ffmpeg
   ```
2. **執行腳本**：
   我們在 `scripts/` 目錄下提供了一個預處理工具：
   ```bash
   python scripts/filter_silence.py input.m4a -o output.m4a -t -40
   ```
   *   `-t -40`：音量門檻（dBFS），數值越小越靈敏（建議範圍 -30 至 -50）。
   *   執行後會標出原始時長與精簡後的時長，這能節省 AI 分析 90% 以上的時間。
   *   此腳本採用的邏輯是：只要音量超過門檻，就截取該片段前後保留緩衝，確保不漏聽。
