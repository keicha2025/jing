# 案時記 / Caselog - 專案與工時紀錄工具 📋

案時記 (Caselog) 專為自由職業者 (Freelancers) 設計，幫助你精確追蹤專案進度、工時投入與收款狀態。

## ✨ 核心特色

- **專案生命週期管理**：記錄從「開發中」到「已完成」的專案狀態。
- **工時手動紀錄**：優化手動補登工時，包含起訖時間、時分拆分與案時備註。
- **財務追蹤系統**：記錄每筆收款對應的金額、日期與備註，自動計算預算達成率。
- **Excel 匯出**：一鍵產生所有歷史紀錄，每個專案獨立工作表分頁。
- **PWA 背景同步**：透過 Firestore Persistence 支援離線登錄，上網後自動同步。
- **現代移動端介面**：底部導覽選單 (Mobile-First)，支援 thumb-zone 操作。

## 🛠️ 技術架構

- **Framework**: Next.js (App Router, Static Export)
- **Database**: Firebase Firestore (`case-log` 資料庫)
- **Auth**: Firebase Google Login (Whitelist 管理)
- **Styling**: Tailwind CSS + Framer Motion
- **Icons**: Material Symbols Outlined

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd caselog
   ```
2. **安裝依賴** (React 19 相容)：
   ```bash
   npm install --legacy-peer-deps
   ```
3. **本地開發**：
   ```bash
   npm run dev
   ```
4. **構建導出**：
   ```bash
   npm run build
   ```
   *注意：構建產物將位於 `dist/`。*

## 📌 注意事項

- 本專案在 `next.config.mjs` 中設定了 `basePath: '/caselog'`。
- 跳轉路由需遵循 Firebase Hosting 的 `rewrites` 規則，詳見根目錄 `firebase.json`。
