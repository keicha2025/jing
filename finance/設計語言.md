# JING Insight 設計語言 (Design Language)

## 1. 核心哲學
* **專業且沉穩**：專案定位為理財與投資決策中心，視覺應避免過於活潑的元素。
* **玻璃擬態 (Glassmorphism)**：使用深色背景搭配半透明表面，營造空間感與現代感。
* **無 Emoji 規範**：全站禁止使用任何文本 Emoji。所有提示與視覺引導必須使用 **Lucide Icons**。
* **禁絕紅色**：移除非必要的紅色元素。對於「刪除」或「危險」動作，改用中性色或品牌輔助色（如深紫色或深灰色），避免產生情緒上的壓力。

## 2. 色彩系統 (Color Palette)
* **背景 (Background)**: `#0f172a` (深藍黑)
* **表面 (Surface)**: `rgba(30, 41, 59, 0.7)`
* **主色 (Primary)**: `#6366f1` (Indigo) 至 `#8b5cf6` (Violet) 的漸層
* **輔助色 (Secondary)**: `#06b6d4` (Cyan) - *取代原有的粉紅色*
* **強調色 (Accent)**: `#8b5cf6` (Purple)
* **文字 (Text)**: 
    - 主色: `#f8fafc`
    - 次要: `#94a3b8` (Muted)
* **狀態色 (Status)**:
    - 成功: `#10b981` (Emerald)
    - 警告: `#f59e0b` (Amber)
    - 錯誤/危險: `#64748b` (Slate 500) - *不再使用亮紅色*

## 3. 字體規範 (Typography)
* **字型**: `Inter`, system-ui, sans-serif.
* **標題**: 粗體 (700)，負字距 (-0.025em)。
* **內文**: 標準 (400) 或 次粗 (600)。

## 4. 組件準則 (Component Guidelines)
* **按鈕 (Buttons)**:
    - 圓角: `0.75rem`
    - 陰影: 柔和的品牌色投影
    - 微互動: 懸停時略微上升 (`translateY(-2px)`)
* **輸入框 (Inputs)**:
    - 背景: 半透明深色
    - 邊框: 聚焦時變為 `var(--primary)` 並帶有外光暈。
* **卡片 (Cards)**:
    - 必須帶有 `backdrop-filter: blur(12px)`
    - 邊框設為 `rgba(255, 255, 255, 0.05)`

## 5. 圖表規範 (Charts)
* 圖表應保持簡潔，背景格線需極淡 (`rgba(255,255,255,0.05)`)。
* 顏色選用應符合上述色彩系統，避免使用粉紅色。
