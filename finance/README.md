# JING Finance - 專業投資儀表板 📈

JING Finance 是一個美感與功能兼具的個人投資管理工具，整合了資產追蹤、預算規劃與 AI 策略分析。

## ✨ 核心特色

- **多幣別資產管理**：支援 TWD, USD, JPY 獨立規劃。
- **AI 策略師 (AI Analyst)**：沉浸式工作台佈局，提供「市場連動與情緒共振」等四種分析模式。
- **智慧排序系統**：依分類 (台股 > 美股 > 基金 > 其他) 與金額自動優化視圖。
- **玻璃擬態 UI**：基於深色模式的專業視覺設計，優化行動端響應式體驗。
- **即時通知系統**：內建自定義 Toast 通知與玻璃擬態對話框。

## 🛠️ 技術架構

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Firebase Firestore, Firebase Auth
- **Utilities**: Recharts (圖表), Lucide React (圖標), Framer Motion (動畫)
- **Deployment**: Firebase Hosting (部署於 `/finance/` 路徑)

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd finance
   ```
2. **安裝依賴**：
   ```bash
   npm install
   ```
3. **本地開發**：
   ```bash
   npm run dev
   ```
4. **構建發布**：
   請在根目錄執行 `bash full_deploy.sh`。

## 📌 注意事項

- 本專案在 `vite.config.ts` 中設定了 `base: '/finance/'`，請勿任意修改以確保部署後的資源路徑正確。
- 資料庫權限由 `firestore.rules` 控管。
