# Email Studio - 直覺郵件發送器 📧

透過極簡介面寄送精美 HTML 格式化的郵件，完美應對各類通知與商務場景。

## ✨ 核心特色

- **Gmail API 直接整合**：直接繞過 CORS 限制並提升發信穩定度。
- **別名選擇系統 (Send As)**：智慧地從 Gmail 設定中抓取你的所有寄件別名，隨意切換。
- **RFC 2047 編碼修正**：完美修復中文主旨與寄件者名稱的亂碼問題，支援多國語言。
- **GAS 背景日誌**：發送紀錄將同步異步存儲於 Google Sheet，保留完整的發信紀錄歷史。
- **沉浸式 UI**：基於 Stone 與白色系的混搭，營造高級設計感。
- **模板預覽區**：所見即所得的 HTML 郵件內容輸入。

## 🛠️ 技術架構

- **Frontend**: HTML5, Vanilla JS, Tailwind CSS
- **API Integration**: Google Sheets API (Auth 2.0 Scope), Gmail API
- **Log Service**: Google Apps Script (`code.gs`)

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd mail
   ```
2. **服務配置**：
   本地執行需確保 `config.js` 包含正確的 Google API Client ID。
3. **本地執行**：
   直接使用伺服器開啟 `index.html`。
