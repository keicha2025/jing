# LoopDashcam - 高效循環錄影行車記錄器 🚗

LoopDashcam 是一個專為 Android 平台開發的高效能、低功耗行車記錄器應用。

## ✨ 核心特色

- **方案 A 高效錄影架構**：採用 `MediaCodec` 硬體解碼器與 `OpenGL ES` 渲染，性能遠超傳統 API。
- **自動循環空間管理 (LoopManager)**：FIFO 自動循環刪補機制，預設 5GB 空間上限，確保儲存不溢出。
- **即時時鐘與 GPS 疊加**：透過 GL 貼圖在影片幀上即時渲染當前時間、車速與經緯度。
- **多鏡頭智慧切換**：支援 主鏡頭、前鏡頭與超廣角鏡頭 (若設備支援) 的無縫切換。
- **互動式操控 UI**：直覺的大紅快門鈕、錄影計時與快取狀態列顯示。
- **高效權限管理**：一站式解決相機、音訊、儲存與位置權限請求流。

## 🛠️ 技術架構

- **Platform**: Android (Min SDK 24, Target SDK 35)
- **Engine**: MediaCodec + OpenGL ES + Camera2 API
- **Language**: Kotlin 2.0+
- **Build Tool**: Gradle 8.10.x, Java 21+
- **UI Architecture**: Single Activity, FrameLayout-based overlay controls.

## 🚀 開發與編譯

1. **進入目錄**：
   ```bash
   cd LoopDashcam
   ```
2. **準備環境**：
   確保你的 Android Studio 已安裝 **SDK 35 (Android 15)** 與 **Java 21 JDK**。
3. **構建 APK**：
   ```bash
   ./gradlew assembleDebug
   ```
4. **安裝測試**：
   連接 Android 設備並執行：
   ```bash
   ./gradlew installDebug
   ```
