# Personal Audio Player - 高效音檔播放器 🎧

個人音檔播放器 (Audio Player) 是一個基於 Vite 與 React 打造的高效播音工具，針對移動設備的操作習慣進行了垂直優化。

## ✨ 核心特色

- **方案一：高效大按鈕佈局**：大面積觸控區域，方便在運動或單手操作時對準控制項。
- **3 秒精準跳轉**：支援自定義 3 秒、10 秒、30 秒等前後跳轉。
- **多段超寬頻變速**：提供 0.1x 到 2.5x 的細膩變速播放。
- **IndexedDB 緩存持久化**：音檔上傳後，斷網或重新整理頁面後依舊存在。
- **清除快取機制**：內建快取容量管理，隨時手動清空已上傳音檔。
- **PWA 安裝支援**：支援離線載入播放器並具備專屬 App 圖示。

## 🛠️ 技術架構

- **Framework**: Vite + React
- **Icons**: Lucide React
- **Styling**: Tailwind CSS
- **Storage**: IndexedDB (透過 `browser-idb-keyval` 或原生 API).

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd preview
   ```
2. **安裝與開發**：
   ```bash
   npm install
   npm run dev
   ```
3. **部署路徑**：
   `/preview/`
