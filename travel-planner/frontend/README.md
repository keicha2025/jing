# Travel Planner - 旅遊規劃視覺化 ✈️

Travel Planner 是一個整合了多個熱門旅遊行程（名古屋、沖繩）並提供直覺行程資訊與視覺化導覽的 Web 應用。

## ✨ 核心特色

- **多套裝行程視圖**：預載了 2024/2025 名古屋與沖繩（兩版）行程規劃。
- **即時地圖與交通**：整合了各地的交通指南與重要地標索引。
- **快速匯率/手續費計算**：內建旅遊相關的小工具（如 tesuuryo.html 手續費計算）。
- **現代響應式頁面**：優化在手機端的滑動與閱讀體驗。
- **極簡美學**：使用 Inter & Noto Sans TC 字體，搭配流暢的圖表呈現。

## 🛠️ 技術架構

- **Framework**: Vue 3 + Vite
- **UI Architecture**: Single-File Components (SFCs), Tailwind CSS
- **Pages**: 多個獨立 HTML 靜態專案 (nagoya, okinawa, okinawa-1)
- **Deployment**: Firebase Hosting (部署於 `/travel-planner/` 路徑)

## 🚀 開發與執行

1. **進入目錄**：
   ```bash
   cd travel-planner/frontend
   ```
2. **安裝依賴**：
   ```bash
   npm install
   ```
3. **本地開發**：
   ```bash
   npm run dev
   ```
4. **構建發布**：
   ```bash
   npm run build
   ```
   *注意：構建產物由 `./full_deploy.sh` 整合至總目錄。*

## 📌 注意事項

- 本前端部分在 `vite.config.js` 中設定了 `base: '/travel-planner/'`。
- 後端位於 `travel-planner/backend/`，包含 GAS 同步與數據轉換腳本。
